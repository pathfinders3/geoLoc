# geoLoc

휴대전화에서 버튼을 누르면 현재 위치(위도/경도/정확도)와 위치 타이틀(사람이 읽을 수 있는 주소/지명)을 표시하는 순수 HTML/JS 예제입니다.

## 실행 방법

1. `index.html` 파일을 브라우저에서 엽니다.
2. `현재 위치 가져오기` 버튼을 누릅니다.
3. 브라우저의 위치 권한 요청을 허용합니다.

## 배포 시 주의사항

- Geolocation API는 `HTTPS`(또는 `localhost`)에서만 동작합니다.
- 실제 웹 호스팅 서비스에 업로드할 때는 반드시 HTTPS 주소로 접속하세요.
- 위치 타이틀은 역지오코딩 API(OpenStreetMap Nominatim)를 통해 조회하므로, 인터넷 연결이 필요합니다.
